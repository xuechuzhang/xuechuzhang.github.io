# Prototype 01 — interface walkthrough

The 42-second MP4 uses five **actual screenshots** captured while interacting with the deployed prototype in Chrome on 9 October 2026. It is a captioned sequence of captured interface states, **not a continuous screen recording**. No UI or experimental outcome was fabricated.

It shows a shared Aster identity; a planning choice in slot 1; a listening choice in an independent slot 2; the immediate human-only handoff preview; and the illustrative payoff calculator. All choices were software demonstrations performed during development. There were no recruited participants, connected human groups, payments, or behavioral observations.

The video does not demonstrate an LLM, actual seven-day elapsed time, participant recruitment, or relational efficacy. Caption text is placed below the unmodified screenshots. The manifest lists the source screenshot hashes, ordering, and durations; the WebVTT file provides the same step captions.
